🖼️ Görsel Yenileme Aracı (v2 — gerçek ekran görüntüsü)

Mevcut etkinliklerin kart görselleri, kod/dosya tiplerinde etkinliğin HTML içeriği, drive tiplerindeyse bağlantının hedef oyun sitesi gerçekten açılıp ekran görüntüsü alınarak üretilir. Bu işlem tarayıcı içinden değil, bilgisayardaki headless Chrome ile yapılır.

  1. Bir terminal aç (Git Bash veya PowerShell).
  2. Şu klasöre git: bilfenbilisimai/digiq/thumbnails
  3. Sırayla çalıştır:
    powershell -NoProfile -ExecutionPolicy Bypass -File hazirla.ps1
    # sonra Chrome döngüsü (shots klasörüne PNG yazar) ve:
    powershell -NoProfile -ExecutionPolicy Bypass -File yukle.ps1
  4. Kart görselleri Supabase'e yazılır; portalda görünür. Tekrar çalıştırmak güvenlidir.

Not: Hazırla + Chrome döngüsü + yükle üç parçalı çalışır; hazır)+yükle zaten bu klasörde bulunur. Chrome yolu: C:\Program Files\Google\Chrome\Application\chrome.exe
